# Test Fixtures

- `sample.txt` — hand-written 3-chapter plain-text story with scene breaks (`* * *`) and two recurring characters (Vance, Marit). Used by `chunking.test.ts` and `adapter.test.ts`.
- `sample.epub` — EPUB version of `sample.txt`, generated by `build-sample-epub.ts`. Used by `epub.test.ts`. Committed so tests are reproducible without running the generator.
- `build-sample-epub.ts` — Bun script to regenerate `sample.epub` from `sample.txt`. Run manually: `bun test-fixtures/build-sample-epub.ts`. Requires `epub-gen-memory` devDependency.
